# BOSS brand and copy brief

## Contract

- **Artifact and channel:** Public GitHub repository, README landing page, terminal masthead,
  CLI/help copy, logo, and hero image for `BOSS`.
- **Audience:** Technical founders, owners, and lead developers who supervise several coding
  agents or repositories and want one accountable operating thread.
- **Reader situation:** They are currently acting as scheduler, project manager, retry loop,
  reviewer, and status dashboard across disconnected agent sessions.
- **Awareness and intent:** Problem-aware and tool-aware; skeptical of another orchestration
  wrapper and alert to fabricated “agent” identity or fake assurance.
- **Emotional state:** Busy, impatient, high-agency, and looking for leverage without surrendering
  final authority.
- **Desired human outcome:** Understand within 30 seconds that BOSS gives them one COO-style Pi
  conversation for real multi-repository software operations, then reach a safe first run.
- **Next action:** Run the verified installer, then type `pi-boss`.
- **Actual value:** Delegate independent work across registered repositories, watch real agents,
  receive only decisions/results, and preserve explicit merge authority.
- **Mechanism:** A persistent COO agent coordinates real Pi agents in Herdr tabs while a
  deterministic control plane owns isolation, workflow gates, budgets, supervision, and evidence.
- **Cost, risk, and alternatives:** Early project; managed production is macOS-only and requires
  Pi, Herdr, Git, and a Codex login. Original Firstmate is broader; plain Pi/Codex is simpler for
  one small task.
- **Voice and constraints:** Decisive, calm, candid, concise. The agent calls the user “Boss” and
  refers to itself as “your COO.” No nautical language, faux-luxury corporate jargon, hustle
  slogans, invented acronym expansion, or claims stronger than executed evidence.
- **Primary metric:** An unaided visitor can state “one thread coordinates real coding agents
  across my repos, and I still approve delivery” and find the install command.
- **Guardrails:** Truth over polish; security boundaries and alpha/platform limits remain visible;
  Firstmate's published captain identity is never modified by BOSS work.

## Performance chain

- **Earliest bottleneck:** Comprehension. “BOSS” alone could sound like a generic management app
  or imply that the agent—not the user—is the boss.
- **Resolution:** Above the fold must say “Your AI COO for software work” and show one Boss
  conversation directing several real agent workstreams while decisions return to the user.

## Message spine

- **Reader reality:** Your coding agents can write code, but you are still managing every thread.
- **Desired progress:** Run several projects from one conversation without losing visibility or
  delivery control.
- **Value:** Hand off coordination while keeping every consequential decision.
- **Mechanism:** Your COO turns requests into isolated work items run by real Herdr Pi agents and
  deterministic evidence gates.
- **Proof:** The complete BOSS suite, fresh installer, live CI, and rendered assets—only after each
  has actually passed.
- **Objection:** It is intentionally narrow, early, Herdr/Pi-specific, and managed production is
  macOS-only.
- **Action:** Install, then run `pi-boss`.

## Taste direction

Reading this as a developer-tool brand for technical owners at the moment they hand off
operations, where authority should feel calm and exact without executive cosplay or generic
enterprise-SaaS gloss.

- **Use:** Obsidian, warm paper, and one signal-green accent; bold grotesk wordmark plus compact
  monospaced operational labels; asymmetric editorial composition; strong vertical “decision
  spine”; flat vector geometry; generous negative space; real command/output receipts.
- **Avoid:** Captain/crew/anchor/compass imagery; crowns, neckties, briefcases, skyscrapers;
  blue-purple gradients; equal-card grids; decorative pills/status dots; fake terminal output;
  glossy 3D; stock-office imagery; an invented expansion of BOSS.
- **Prove:** The `BOSS` name reads first, “your AI COO” resolves the role immediately, the logo is
  recognizable at 32 px, the hero explains one-to-many coordination without prose, all SVG text
  remains legible at GitHub width, and raster assets have no watermark or stray text.
- **Composition grammar:** Wordmark and promise occupy the first beat; an offset operations spine
  carries the eye through request → COO → concurrent agent lanes → exact decision. Sections vary
  between full-width evidence, narrow prose, and comparison tables rather than repeating cards.
- **Typography:** System sans for outcome copy; system mono for commands, IDs, state, and proof.
- **Signature move:** A geometric `B` made from one vertical operating spine and two returning
  decision loops. The same shape becomes the hero's routing diagram.
- **Five default patterns rejected:** centered gradient blob, generic dashboard cards, random
  glassmorphism, ornamental status lights, and a fake terminal screenshot.

## Rebrand boundary

BOSS inherits the control-plane behavior but not Firstmate's identity. Public and runtime-facing
names become `BOSS`, “your COO,” “Boss,” `pi-boss`, and `pi-boss-quit`. Internal package, command,
environment, state-home, skill, process-kind, branch, and Herdr-session namespaces must also be
distinct so both products can coexist without sharing or corrupting state. Provenance and honest
comparison may name Firstmate; no other nautical residue ships.

## Test plan

- **Control:** Firstmate Graph at the source commit recorded in BOSS history.
- **Treatment mechanism:** Role/terminology/visual-system change plus fully isolated runtime
  namespaces; control-plane algorithms stay fixed.
- **Hypothesis:** A technical owner will identify the “one thread, AI COO, real agents, final
  authority stays with me” story faster than from an architecture-led or nautical presentation.
- **Primary outcome:** Unaided 30-second comprehension (not measured in this implementation turn).
- **Guardrails:** Full deterministic suite, fresh install, CLI/help, coexistence, asset render,
  links/anchors, diff hygiene, and live CI all pass.
- **Decision rule:** Publish only if mechanical guardrails pass; call the landing page a candidate,
  not a performance winner, until real reader testing exists.
